The requirements and acceptance criteria remain authoritative in [TRADING_IMPROVEMENTS.MD](src/rust/auto_trader/TRADING_IMPROVEMENTS.MD). Durable ownership and dependencies are recorded in Beads; this file is a status snapshot, not a replacement task ledger or a change to the requirements.

## User-confirmed contracts

- Worker decision reports carry distinct versioned event and episode IDs. Each source update gets a stable event ID; unchanged thesis fields (strategy, symbol, profile, direction, accepted market-state key) continue the same deterministic episode across updates and worker restarts. Changes in supported thesis dimensions reset the episode. A same-key close/reopen reset cannot be established from current state, so the prior episode is conservatively reused and dedup may keep blocking it.
- Re-entry cooldown and episode reset begin only after a stop fills completely and the position is fully closed. Partial stops and non-stop exits do not reset the episode. After expiry, re-entry requires a fresh versioned event and a worker report carrying the acknowledged durable reset generation.
- Feed freshness is per symbol and tied to active book subscription, current book mark, and sampled history. Held symbols are explicitly requested. Proxy hedges fail closed without fresh source-provided status; the global stream idle timeout is not a symbol guarantee.
