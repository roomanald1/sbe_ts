# Insights

Insights consumes raw ticker batches and market events from FeedHandlers over RSocket. It computes rolling one-minute and five-minute realized volatility from timestamped prices, uses the one-minute value in its signal engine, and publishes enriched price events from its own RSocket server on port 10004. Enriched prices use the distinct `EnrichedSymbolPrice` SBE template (ID 4); FeedHandlers' `SymbolPrice` template (ID 1) remains raw. The `tickers:*` request serves enriched price events to the browser; `signal-events:*` serves enriched price, book, and trade events to internal consumers.

Insights always runs its live signal-push path to AutoTrader and Learning. It captures research records at the coarse research cadence and sends them to the background persistence worker; this does not switch off or replace live signal generation. There is no `INSIGHTS_RESEARCH_ONLY` mode or separate Live Signals producer.

Process-local market state is bounded: active per-symbol engines and their latest delivery/UI/book/price/volatility caches are capped at 256 symbols by default and expire together after 60 seconds idle. FeedHandlers currently selects the top 100 spot instruments, leaving 2.5× headroom for configured subscriptions. If the cap is reached while every engine is active, Insights rejects a new symbol rather than evicting rolling state still needed for live signals. News attribution pending state expires after 60 seconds and is capped at 8,192 entries. Research history and the dashboard calibration window live in SQLite; the dashboard-only calibration window caches at most 1,000 snapshots and 5,000 outcomes for up to 15 seconds. Live signal generation does not read this cache. These limits can be tuned with `INSIGHTS_MAX_ACTIVE_SYMBOLS` and `INSIGHTS_SYMBOL_IDLE_TTL_MS`.

Insights owns live market-signal calculation and delivery, raw research/outcome storage, news classification, and daily strategy signal generation. It does not calculate missed-opportunity policy evidence or publish an AutoTrader live-context payload. Learning owns context thresholds and missed-opportunity evidence: it joins an attributed skipped live-strategy candidate to persisted 10-second snapshots and book marks after configured horizons. Only complete coverage produces gross directional mid-markout diagnostics; Insights never derives bands from generic raw signals or presents these marks as net/executable returns. Strategy-profile decisions, walk-forward evidence, and replay analysis belong to Learning and Strategy X; Insights publishes no generic signal walk-forward results. RSocket on port 10004 serves market-data streams, port 10007 serves internal service requests, and port 10011 serves browser queries, mutations, UI snapshots, and news snapshots. HTTP on port 3004 is operations-only (health, metrics, and documentation). Exchange and vendor API requests remain HTTP.

Configure the Insights market-event listener with `INSIGHTS_RSOCKET_PORT` (default `10004`), the service RPC listener with `INSIGHTS_RPC_RSOCKET_PORT` (default `10007`), and the browser listener with `INSIGHTS_BROWSER_RSOCKET_PORT` (default `10011`). The React app uses `VITE_INSIGHTS_RSOCKET_URL` and `VITE_INSIGHTS_BROWSER_RSOCKET_URL`. The news-sentiment classifier is called over RSocket request-response; its HTTP listener is for health and process metrics only.
