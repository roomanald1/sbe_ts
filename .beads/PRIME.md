# Beads workflow

- Follow repository AGENTS.md.
- Use Beads for all task tracking.
- Create and claim issues before implementation.
- Use bd ready and bd show for task selection and details.
- Search bd memories <keyword> before broad repository searches.
- Use bd remember for verified reusable repository knowledge.
- Inject only task-relevant knowledge into child agents.
- Record progress, decisions, blockers and validation evidence.
- Recover active task state after compaction or session restart.
- Run required quality gates before closing issues.
- Check git status before handoff.
- Never commit, push or sync without explicit authority.
- Close completed issues and report remaining work.
